# 06: 解锁与写入

**What to build:** 访客只读。页脚「编辑」输入 Read Token 之后，这台浏览器解锁，才出现新收录、改、删。编辑界面是同一套纸感，字段仍是标题、网址、描述、标签。MCP 不用改。

**Blocked by:** 05: 窄屏

**Status:** done

- [ ] 未解锁时，页面上没有新收录、改、删
- [ ] 页脚「编辑」打开一个纸感输入框
- [ ] Read Token 只留在这台浏览器；清掉站点数据或换浏览器，要再输一次
- [ ] 钥匙不对时不能解锁，已有的 Bookmark 不被改动
- [ ] 解锁后工具条出现「新收录」
- [ ] 解锁后，索引的「改」和「删」在箭头左侧，不新增表头；窄屏也一样，不占新的一行结构
- [ ] 解锁后，陈列的「改」和「删」在标签那一行的末尾
- [ ] 编辑字段仍是标题、网址、描述、标签，走现有写入接口
- [ ] 编辑界面是浅色纸感，不是旧的紫黑抽屉
- [ ] 新增、修改、删除之后，陈列、索引、计数和标签分布跟着变
- [ ] MCP 的四个工具和 Bearer 鉴权保持原样
