# 05: 窄屏

**What to build:** 视口小于 768px 时，整页换成窄屏稿。顶栏变短，色条不写百分比，标签一行滑出去，陈列变成单列，索引换成窄的行。768px 及以上仍是宽屏稿。

**Blocked by:** 04: 宽屏索引

**Status:** done

- [ ] 小于 768px 用窄屏稿，大于等于 768px 用宽屏稿，没有第三套
- [ ] 窄屏顶栏只有卷号和更新日期，没有居中的英文标题
- [ ] 标题、印章、英文句子、简介和三个计数上下堆叠
- [ ] 窄屏色条不写百分比
- [ ] 标签一行横向滑出，不换行
- [ ] 陈列是单列，卡片内容和宽屏一样
- [ ] 窄屏索引一行是编号、名称、箭头、换行的简介、域名
- [ ] 窄屏索引不显示标签
- [ ] 页脚的「完」和说明左对齐、上下排
- [ ] 检索、筛选、排序和看法在窄屏上仍然记在地址栏里
