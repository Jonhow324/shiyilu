# 03: 宽屏陈列

**What to build:** 公开页换成「拾遗录」的宽屏陈列。页眉、标签分布、检索、标签、错位拼贴、Showing 和页脚都按稿子。封面现取，取不到是「显影中」。筛选、检索和排序记在地址栏里。旧的紫黑壳删掉，这一张先不保证索引和窄屏。网页上暂时不能改 Bookmark，MCP 还能写。

**Blocked by:** 02: 收录日与种子

**Status:** done

- [ ] 打开首页看到「拾遗录」，不再是紫黑侧边栏和卡片网格
- [ ] 宽屏顶栏有卷号、「A Cabinet of the Web」和更新日期；更新日期是最近一条收录日
- [ ] 页眉有印章、英文句子、中文简介、收录数、标签数、某年新增；年份取最近一条收录日的年份
- [ ] 标签分布按挂载次数算百分比，可以加起来超过 100%；宽度和百分比不随当前筛选变化
- [ ] 点色块和点标签是同一件事，可多选，再点一次取消，只留下同时具备的 Bookmark
- [ ] 标签上的计数是全库里带这个标签的 Bookmark 数，不随筛选变化
- [ ] 稿子里的十个标签用固定色，其余标签用一个刷新不变的备用色
- [ ] `/` 把光标放进检索框；检索词、选中的标签、排序写在地址栏里，刷新还在
- [ ] 排序只有最近收录和最早收录
- [ ] 陈列按稿子的尺寸节奏循环，条数不是 22 时继续同一套节奏
- [ ] 点封面或标题打开那个网址
- [ ] 封面走自己的接口，浏览器看不到截图服务的地址；失败或加载中显示「显影中」
- [ ] 封面接口拒绝非 http(s)，上游失败时调用方能显示「显影中」；这条有测试，且不打真实的截图服务
- [ ] Showing 显示筛完的条数和全库总数
- [ ] 这页不跟系统暗色反色
- [ ] 旧的主题切换和侧边栏编辑壳不再出现
