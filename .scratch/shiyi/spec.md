# 拾遗录

## Problem Statement

Nav 的公开页还是一套紫黑侧边栏加卡片网格。它和已经画好的「拾遗录」不是同一个东西：没有陈列，没有索引，没有标签分布，封面也不存在。Bookmark 的字段够用，缺的是按稿子把它们呈现出来，以及让检索、筛选、排序和稿子上写的字一致。

## Solution

公开页换成「拾遗录」。同一批 Bookmark 有两种看法：宽屏的错位陈列，和一张索引表。窄屏有自己的稿，不另造第三套。访客只读。页脚「编辑」用 Read Token 解锁之后，才能新收录、改、删。数据、MCP、鉴权不动。

## User Stories

1. 作为访客，我要一打开就看见「拾遗录」，以便确认这是那本私人网页收藏目录。
2. 作为访客，我要在宽屏顶栏看到卷号、"A Cabinet of the Web" 和更新日期，以便知道这是第几卷、最近什么时候收录过。
3. 作为访客，我要在窄屏顶栏只看到卷号和更新日期，以便窄屏不被居中的英文标题挤占。
4. 作为访客，我要看到标题旁的印章「网藏私印」，以便页面有稿子上的那枚印。
5. 作为访客，我要读到 "Things worth returning to." 和那段中文简介，以便知道这页在陈列什么。
6. 作为访客，我要看到收录数、标签数和「某年新增」数，以便一眼知道柜子里有多少东西。
7. 作为访客，我要「更新于」取最近一条收录日，以便日期和真实数据一致。
8. 作为访客，我要「新增」的年份取最近一条收录日的年份，以便种子数据能显示「2025 新增 04」，而不是今年的 0。
9. 作为访客，我要标签分布按标签被挂上的次数算百分比，以便一条 Bookmark 挂两个标签时两边都计一次。
10. 作为访客，我要点色块筛选，以便只看某一类。
11. 作为访客，我要色条的宽度和百分比不随当前筛选变化，以便它始终是整个柜子的画像。
12. 作为访客，我要在宽屏色条下看到「设计 14%」这样的字，以便知道每一段是什么。
13. 作为访客，我要在窄屏色条下不看到这些字，以便窄屏色条还能放下。
14. 作为访客，我要按 `/` 把光标放进检索框，以便不用先点一下。
15. 作为访客，我要检索匹配名称、简介或网址，以便搜 `tldraw.com` 也能找到。
16. 作为访客，我要检索不区分大小写，以便大小写不影响结果。
17. 作为访客，我要标签可以多选，并且只留下同时具备这些标签的 Bookmark，以便逐步收窄。
18. 作为访客，我要再点一次已选标签就取消，以便不用找单独的清除按钮。
19. 作为访客，我要标签上的计数是带这个标签的 Bookmark 数，以便和色条的百分比不是同一套数字。
20. 作为访客，我要标签计数也不随当前筛选变化，以便知道全库里每一类有多少。
21. 作为访客，我要在窄屏把标签一行横向滑出去看，以便十个标签不用挤成多行。
22. 作为访客，我要在陈列和索引之间切换，以便同一批 Bookmark 有两种看法。
23. 作为访客，我要默认看见陈列，以便落地就是稿子上的那一版。
24. 作为访客，我要在宽屏看到按稿子节奏循环的错位拼贴，以便条数不是 22 时仍然像这张稿。
25. 作为访客，我要在窄屏看到单列陈列，以便不用横向拖一张 2560 的画布。
26. 作为访客，我要点封面或标题打开那个网址，以便从这页走出去。
27. 作为访客，我要封面按网址现取，以便不用把图片存进仓库。
28. 作为访客，我要封面还没到或取失败时看到「显影中」，以便空封面也是稿子上的样子。
29. 作为访客，我要在宽屏索引里看到编号、名称、简介、标签和访问，以便快速扫过。
30. 作为访客，我要宽屏简介一行放不下就截断，以便一行还是一行。
31. 作为访客，我要在窄屏索引里看到编号、名称、箭头、换行的简介和域名，以便窄屏读得完一句简介。
32. 作为访客，我要窄屏索引不显示标签，以便和那张窄屏稿一致。
33. 作为访客，我要点索引的整行打开网址，以便不用去找单独的链接。
34. 作为访客，我要按最近收录或最早收录排序，以便两种方向都有。
35. 作为访客，我要排序只有这两个方向，以便没有稿子上没画的第三种。
36. 作为访客，我要刷新后还停在刚才的检索、标签、看法和排序上，以便地址栏能记住。
37. 作为访客，我要复制这个地址给自己，以便另一台浏览器打开是同一批 Bookmark。
38. 作为访客，我要看到「Showing n / 总数」，以便知道筛完还剩多少。
39. 作为访客，我要编号是 Bookmark 的 id 补零到三位，以便删掉一条时其余编号不动。
40. 作为访客，我要卡片上的日期是收录日，以便它不跟着后来的修改变。
41. 作为访客，我要稿子里的十个标签用固定色，新标签用一个刷新不变的备用色，以便颜色不是随机的。
42. 作为访客，我要这页不跟系统暗色反色，以便纸感还是纸感。
43. 作为访客，我要在 768px 以下看到窄屏稿、以上看到宽屏稿，以便没有第三套我没画过的布局。
44. 作为访客，我要页脚看到「完」和收录数，以便知道这页到头了。
45. 作为持有 Read Token 的人，我要从页脚「编辑」解锁，以便访客页上没有写入按钮。
46. 作为持有 Read Token 的人，我要钥匙只留在这台浏览器，以便换一台就要再输一次。
47. 作为已解锁的人，我要看到「新收录」，以便不用回到旧的侧边栏。
48. 作为已解锁的人，我要在索引行尾的箭头左侧看到「改」和「删」，以便不新增一列表头。
49. 作为已解锁的人，我要在陈列的标签行末尾看到「改」和「删」，以便阅读态的卡片和稿子一致。
50. 作为已解锁的人，我要编辑的字段仍是标题、网址、描述、标签，以便写入能力和现在相同。
51. 作为已解锁的人，我要编辑界面也是浅色纸感，以便这页上不再同时存在两套外观。
52. 作为维护者，我要 `npm run seed` 写入稿子里的 22 条并删掉那 8 条旧示例，以便空库跑一次就是这张稿。
53. 作为维护者，我要种子不删我自己加的 Bookmark，以便测试数据不会清掉正在用的库。
54. 作为维护者，我要空库时编号归零再写入，以便 Figma 是 No.001、tldraw 是 No.022。
55. 作为维护者，我要库里已有自己的 Bookmark 时不归零，以便已有编号不被重排。
56. 作为助手，我要 MCP 的四个工具保持不变，以便现有接入不用改。

## Implementation Decisions

- 公开页替换现有首页。旧的紫黑侧边栏、卡片、主题切换和 shadcn 壳删除。不保留并行路由。
- 词汇以 `GLOSSARY.md` 为准。封面不入库，见 ADR-0004。Read Token 的鉴权方式不变，见 ADR-0003。
- 数据模型不增字段。编号取 id，收录日取 `created_at`。封面按 URL 现取。
- 列表查询要改两处，否则和稿子矛盾：检索加入网址；排序改为收录日，而不是现在的 `updated_at`。标签过滤保持 AND。这推翻的是现有查询实现，不是某条 ADR。
- 页眉计数、标签分布、标签计数由同一批全库 Bookmark 在页面侧算出。筛选和检索只影响「Showing」和下面的陈列或索引。
- 标签分布的分母是全部挂载次数，不是 Bookmark 数。百分比可以加起来超过 100%。
- 「新增」的年份取最近一条收录日的年份。没有 Bookmark 时，年份用当年，计数为 0。
- 稿子里的十个标签颜色写死。其余标签按名字从一个小的哑色色板里取稳定的一项。
- 陈列的宽屏跨度按稿子节奏循环：一大一小错位、三个中等、再换边。条数不是 22 时继续同一套节奏。窄屏单列。
- 索引有两套列，不共用一套再靠隐藏列凑。宽屏：编号、名称、简介、标签、访问，简介截断。窄屏：编号、名称、访问、换行的简介、域名，不显示标签。分界是 768px。
- 筛选、检索词、看法、排序写进地址栏查询参数。默认是全部、陈列、最近收录。
- 封面接口只接受 http 和 https。服务端向 mShots 取图，失败或超时让页面显示「显影中」。响应不包含 mShots 的地址。不换别的截图服务。
- 种子数据换成稿子里的 22 条，收录日写入 `created_at`。只删除那 8 条旧示例的 URL。仅当删除后库为空时，才把自增序列归零，再按收录日从早到晚插入。重复执行不产生重复行。
- 解锁状态只存在这台浏览器的 localStorage。未解锁不渲染新收录、改、删。编辑字段仍是标题、网址、描述、标签，走现有写入接口。
- MCP 工具、Bearer 鉴权、SQLite 单文件不改。

## Testing Decisions

好的测试只看外部行为，不看页面怎么排。

- Bookmark 模块是主缝。测：检索匹配网址且不区分大小写；标签同时具备；按收录日而不是修改日排序；编号补零且不随排序变化；标签分布的分母是挂载次数；页眉的「更新于」和「某年新增」取最近一条收录日。用临时数据库，不启动浏览器，不打 HTTP。
- 封面接口是第二条缝。测：非 http(s) 被拒绝；上游失败时调用方得到可以显示「显影中」的结果；响应里没有 mShots 的地址。上游用假的，不打真实的 mShots。
- 页面不写自动化测试。种子数据灌入后，用宽屏和窄屏稿对照验收。
- 仓库里目前没有测试。新测试跟着这两条缝，不另起一套页面测试框架。

## Out of Scope

- 窄屏和宽屏之外的第三套布局。
- 按标题、按编号或其他排序。
- 标签的「命中其一」。
- 封面入库、换截图服务、构建时下载图片。
- 多用户、会话、cookie 登录。
- 改 MCP 工具的形状。
- 暗色模式。
